# Property-specific starting estimates — requested October 22, 2026

Status: learner-requested product change; implementation pending the Gemini reliability investigation. The learner asked to prefill “Explore the numbers” with the best available estimates for the confirmed property instead of requiring every input manually.

## Intended behavior

- Populate editable starting assumptions after parcel confirmation, using available quoted listing information, dated public evidence and explicitly labeled estimates. Keep the source record intact alongside the estimate.
- Each estimated value needs a reason, source/data date when available, confidence/limitations and an uncertainty range where meaningful. Distinguish sourced facts, copied claims, generic cost assumptions and property-specific model estimates.
- Proposed purchase must not silently equal assessment, a nominal historical sale, auction opening bid or judgment. Resale/rent assumptions need evidence suited to those quantities; agreeing with an AI does not verify them.
- Renovation defaults are provisional allowances for an uninspected property, not discovered defects or contractor quotes. Public tax records do not establish interior area, condition, bedrooms or bathrooms. Do not fabricate those to make an estimate look property-specific.
- Preserve user edits when estimates arrive; offer a clear way to accept/reset defaults. Bind each estimate to the confirmed parcel and current evidence; reject late estimates for an old property. Changes still invalidate earlier AI analysis.
- Where no defensible basis exists, expose the missing evidence and a way to enter it. Do not disguise an arbitrary number as a reliable estimate just to fill the form. The objective is useful starting values with visible uncertainty.
- Keep the free-tier/no-purchases boundary, finite/range guards and deterministic calculation engine. Gemini proposes typed assumptions and explains their basis; ordinary code validates and calculates results. No automatic buy/sell recommendation.

## Acceptance work

Prove the available model can produce supported estimates on the documented public property, with accurate source references and no invented attributes. Test missing/contradictory data, nominal sales, stale evidence, malformed numbers, human edits during requests and property changes. Verify that the displayed assumptions, calculations and AI review use the same current snapshot. Revisit the permitted data/comparable coverage before promising a market valuation.
